# Prompt Consistency Research Reference

> Research performed with You.com on 2026-08-30. This is a record of source findings, not a
> provider guarantee. Official OpenAI guidance is separated from third-party and community claims.

## Conclusions allowed by the evidence

- A reusable, unchanged style block is a reasonable product strategy for consistency, but it is not a provider guarantee.
- A post-specific style lock can hold aesthetic properties while each slide changes subject, composition, focal point, metaphor, and on-image text.
- Concrete medium and visual properties are preferable to a short style label alone.
- Exact quoted text, explicit typography constraints, and explicit no-extra-text exclusions are supported prompting practices.
- Exclusions can reduce unrequested elements but cannot guarantee their absence.
- No feature may depend on same-seed behavior because the cited official GPT Image guidance does not document a `seed` parameter.
- For production-critical typography, a separate design/editing tool may still be required; the application only creates prompts.
