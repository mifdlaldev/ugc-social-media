## Scope and reading rules

- The 500-command PDF is broader than image generation. Its own structure identifies Bagian 3 (201–300) as the AI-image, photography, cinematic-style, and art-design section.
- Bagian 1 contains visual explanation and layout commands that may be relevant to an educational carousel; Bagian 2, 4, and 5 are not automatically image-generation features.
- The 50-command PDF is an examples handbook: every item has a short form and a detailed form. The detailed examples add concrete elements, style, layout, format, and sometimes text language.
- Slash commands are conventions in the supplied documents. They are not assumed to be native ChatGPT, GPT Image, Nano Banana, Recraft, or other provider API commands.
- A command describes a visual direction; it does not authorize adding facts. Engineering facts, numbers, materials, dimensions, named methods, and claims must still originate from approved research and the owner topic.
